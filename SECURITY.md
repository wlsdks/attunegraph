# Security policy

Please do not report suspected vulnerabilities in a public issue. Use the
repository's private GitHub security-advisory flow and include a minimal,
non-sensitive reproduction, affected commit, impact, and suggested mitigation.
Do not attach personal graph data, database files, credentials, or source
receipts.

AttuneGraph is a local library. Reports about filesystem authority, SQLite
worker isolation, portable artifact validation, provenance/permission bypasses,
or unsafe state mutation are especially useful.
